## 本轮踩到并修掉的 4 个缺陷

### 1. `chat()` 从不发 max_tokens（致命）
第 25 题逻辑推理陷入循环，卡死 13 分钟，会一直算到耗尽 131072 上下文。
修：默认 `max_tokens=16384`（实测最大合法输出 11126，不截断）+ `deadline_s=300` 墙钟硬截止。

### 2. 超时被当成错误
修：`mark_error` 区分 `timed_out`，报告里能分辨「端点坏了」与「模型停不下来」。

### 3. sandbox 用 `tempfile.mkdtemp()`（0o700 写不进）
第 91 题 Python 判分崩、第 99 题 SQL 判分崩。
**第一次只修了 Python 路径，SQL 路径漏了** —— 同一个坑踩两次。
修：两条路径统一到 `_work_dir()`（`makedirs` 在项目内），并加 `finally` 清理。

### 4. `max_tokens=None` 被当成「用默认值」
修：`_UNSET` 哨兵区分「没传」与「显式关闭」。
