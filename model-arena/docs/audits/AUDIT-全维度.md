## 审计中踩到的两个坑

### 坑 1：套件级结果的维度不在 summary

`LEVEL_*` 文件记录整个套件，维度在 `records[].dim`，不在 `summary.dim`。
读错位置会把 36 个文件、1055 题归为「维度未知」。

### 坑 2：D9 判分依据分散在两个文件

```
datasets/d9_baseline.jsonl    32 题（d9_dsh_*）
datasets/full/D9_full.jsonl   78 题自带 checks（d9m_*）
```

只读一个文件会把 78 题报成「题库缺失」。

---

## 局限

1. **审计只反映「当前判分器怎么看历史回答」**，不能说明当时为什么那样判。
2. 同一题多次跑过时只取最新一次，旧版本回答会被覆盖。
3. 判分器版本不同的旧结果，翻正不代表当时是 bug——可能只是判分器后来改进了。
